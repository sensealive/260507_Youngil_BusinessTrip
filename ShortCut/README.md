# ShortCut

GitHub Pages 배포 후 이 폴더에 `.url` 바로가기 파일을 둡니다. 파일은 ASCII(퍼센트 인코딩) URL만 저장해야 합니다.

## 만드는 방법

1. `영일출장자현황.url.template` 을 복사해서 `영일출장자현황.url` 로 이름을 바꿉니다.
2. `URL=` 의 주소를 실제 GitHub Pages 주소로 바꿉니다.
3. 다른 PC에서 더블 클릭해도 같은 사이트로 열리는지 확인합니다.

## 예시

```
[InternetShortcut]
URL=https://sensealive.github.io/260507_Youngil_BusinessTrip/
IconIndex=0
```
